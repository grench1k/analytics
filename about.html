📊 Market Analytics

Дашборд для мониторинга и анализа трёх классов активов: акций РФ, облигаций (ОФЗ) и криптовалют.

🔌 Источники данных

  • CoinGecko API — цены и история криптовалют (BTC, ETH, BNB, SOL, XRP)
  • MOEX ISS API — акции РФ (SBER, GAZP, LKOH, GMKN, VTBR) и ОФЗ
  • Данные аналитиков — целевые цены и прогнозы из открытых источников

MOEX без авторизации отдаёт данные с задержкой ~15 минут.

🎯 Функции

Рекомендации

Топ активов по потенциалу роста с указанием целевых цен, горизонтов и рисков.

Технические индикаторы

  • RSI (14) — сигнал перекупленности/перепроданности
  • MACD — бычий/медвежий тренд

Портфель

Учёт позиций, расчёт P&L и доходности. Данные сохраняются в браузере (localStorage).

⚠️ Важно

Всё, что вы видите на сайте — не является инвестиционной рекомендацией. Прогнозы аналитиков носят справочный характер. Перед принятием решений консультируйтесь с финансовым советником.
